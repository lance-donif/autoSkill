# 仪表盘对齐线

仪表盘使用共享的内边距变量和参考线检查侧边栏、表格、页面容器与浮层。对齐对象是文字、图标和可见控件的墨水边缘，不是不可见按钮的点击区域。参考线用于发现偏离，不代替人工视觉复核。

## 共享 inset 与边线口径

共享变量定义在 `skills/autoskill/app/ui/css/tokens.css`。调整间距时复用这些变量，不在各组件中另写一套数值。

- `--side-row-inset`：侧边栏导航和底部状态行的行内边距。这些行从侧边栏的盒线向内缩进，图标落在共享图标列中。
- `--side-icon`：侧边栏图标列宽度。较窄的状态点在该列内居中。
- `--side-label`：侧边栏标签线相对侧边栏内容起点的位置，由行内边距、图标列和间距组成。品牌标识较宽，从盒线开始；品牌名称仍落在标签线上。
- `--table-inset`：表格首列和末列的内边距，同时用于用例表工具栏。已有内边距的面板（压测图表面板）将它设为 `0px`，使表格文字与面板文字共用起始线。卡片体内直接嵌的表格（如工作流详情的执行阶段表）仍沿用默认内边距，与卡片文字相差 20px；这类详情页目前不在批量审计的场景内。
- `--btn-sm-pad`：小按钮的文字内边距。窄屏范围栏换行时，幽灵按钮用等量负外边距让文字落在起始线上，同时保留完整点击区域。

探针按容器测量起始线、标签线、图标列中线、尾线和尾列中线。普通内容按行分组；表格按列比较单元格的墨水边缘，并检查同一正文行的垂直居中。参考线取测量值中的主导位置，与参考线相差不超过 1px 不记为偏离，相差 2px 及以上记为一条偏离记录。

## 批量审计

先安装项目依赖，并指定本机 Chromium 或 Chrome 可执行文件。在仓库根目录运行：

```bash
export AUTOSKILL_CHROMIUM="/path/to/chrome"
python scripts/gridlines_audit.py --scheme both
```

默认目标是由本仓库静态文件提供、使用 `preview/fixtures.json` 的 Pages 预览。`--scheme both` 检查浅色和深色配色；每个适用场景分别在 1440×900 和 390×844 视口下测量。

检查正在运行的本机仪表盘，或只检查部分场景时，使用：

```bash
python scripts/gridlines_audit.py --url http://127.0.0.1:8787/ --only cases,replay-settings
```

`--chromium` 可直接指定浏览器；`--out` 可指定输出目录。默认输出到 `.gridlines/`：

- `summary.md`：截图数、偏离记录数、未覆盖状态和逐场景偏离数。
- `report.json`：供程序读取的完整汇总。
- `<场景>-<宽度>[-dark].png`：画了参考线的截图。
- 同名 `.json`：容器、参考线、行、表格列线和偏离记录的原始测量结果。

偏离记录按外壳、页面和浮层分组。默认情况下，存在偏离时命令仍以 0 退出；`--fail-on-miss` 使存在偏离的命令以 1 退出。浏览器或依赖缺失、参数错误以 2 退出。未覆盖表示对应状态没有完成测量，不表示该状态通过对齐检查。

## 人工复核

探针使用启发式规则识别文本行、可见控件、居中内容、表格列和 CSS 伪元素。它不计算置信度，也不能把每条偏离记录直接判定为视觉缺陷。居中内容、多行文本、表格、多列面板和伪元素的测量结果应按低置信线索处理。

复核时打开同名 PNG 和 JSON，确认容器范围、元素可见性、实际墨水边缘与预期布局。跨配色和两种视口比较同一偏离，并单独处理未覆盖状态与页面脚本错误。不得只为了让偏离数归零而修改业务预期或测试判定；确认是界面问题后，再调整共享 inset 或对应组件样式。
