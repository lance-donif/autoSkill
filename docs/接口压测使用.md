# 使用已有接口用例做压测

打开仪表盘，进入「执行记录 → 压测记录」。也可以在「测试用例」里从单条接口、勾选的接口或项目打开压测配置。页面用例通过「运行」回放。

## 性能测试

填写「并发数」，再填写「持续时间（秒）」或「目标请求数」。两项都填时，先达到的条件停止发起新请求，已发出的请求继续等待响应。虚拟用户就绪后从内置集合点统一出发，持续时间从放行时开始计算。选中多个项目时，每个项目独立应用同一配置。

目标请求数以实际发起的所选接口请求为准。自动执行的前置接口用于准备 Cookie、鉴权和依赖数据。同一次运行里的不同虚拟用户保持独立会话，用例、断言和配置以启动时冻结的版本为准。

## 压力测试

填写初始并发、每级增加人数、最高并发和每级持续时间。Locust 随阶段增加并发，保持最高并发一个阶段后结束派发。报告按请求开始的阶段归类，可以查看全部或单一阶段。

## 报告

性能测试报告先显示请求汇总、统计和 APDEX。压力测试报告先展示活动用户、吞吐量和响应时间随负载的变化。统计使用 JMeter 5.6.3 的字段和计算口径，支持查看错误及各采样器的常见错误。「下载 HTML 报告」可在断网环境打开。[JMeter 报告指标](https://jmeter.apache.org/usermanual/generating-dashboard.html)

Locust 随新版 Windows x64、Linux x64 和 Linux ARM64 离线包安装。源码环境从仓库根目录安装对应平台的 requirements 后，可启动仪表盘。

```bash
PYTHONPATH=skills/autoskill/app python -m autoskill dashboard --port 8787
```
