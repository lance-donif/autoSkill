# 平台与第三方支持

核对日期：2026-11-14。区分第三方提供原生程序、发行版官方支持、autoSkill 实测。

| 第三方 / 固定版本 | Linux x64 | Linux ARM64 | 统信 UOS ARM64 适配方式 |
| --- | --- | --- | --- |
| agent-browser 0.43.0 | `@agent-browser/cli-linux-x64-gnu` | `@agent-browser/cli-linux-arm64-gnu` | 原生 `bin/agent-browser`，glibc 2.28 构建目标，无需 Windows 程序仿真 |
| Playwright Python 1.62.0 | manylinux1 wheel | manylinux_2_17_aarch64 wheel | 自带驱动，显式启动原生 Chromium；UOS 不在官方发行版清单内，需真机验证 |
| Selenium Python 4.38.0 | Python 绑定可用 | Python 绑定可用 | 显式传 chromedriver 的 Service，避免调用不支持 ARM64 的旧版 Selenium Manager |
| Chrome for Testing 157.0.8103.78 | 官方 linux64 Chrome + driver | 官方 linux-arm64 Chrome + driver | 新系统用包内浏览器；旧 UOS 可用系统 Chromium 与匹配驱动，不能仅凭 CPU 一致宣称兼容 |
| Python 3.12.10 | 原生可搬移构建 | 原生可搬移构建 | Astral python-build-standalone，不依赖 UOS 默认 Python |
| cryptography 50.0.0 等 Python 库 | 固定版本二进制 wheels | 固定版本二进制 wheels | 选 manylinux2014 / manylinux_2_28，最低 glibc 2.28；浏览器另有共享库要求 |
| Node 24 / DSH Web | Node 官方 Tier 1 | Node 官方 Tier 1 | DSH 单独安装；Node 24 要求内核 >= 4.18、glibc >= 2.28、libstdc++ >= GLIBCXX_3.4.25；DSH 要求 Node >= 24.9 |

Playwright 当前官方 Linux 名单：Debian 12 / 13、Ubuntu 22.04 / 24.04 / 26.04，x86-64 / arm64，**不包括统信 UOS**。系统 Chromium 是 autoSkill 提供的适配入口，需要在具体 UOS 验证。ARM64 wheel 能安装不代表浏览器能启动。

Chrome for Testing 从 **153.0.8001.0** 起提供 Linux ARM64，不能套用旧的「没有 ARM64」结论。Selenium Manager 的 ARM64 支持到 4.49.0 才加入，本项目固定的 4.38.0 使用显式驱动，不依赖这一能力。

## 官方依据

- [agent-browser 0.43.0](https://github.com/vercel-labs/agent-browser/releases/tag/v0.43.0)；[glibc 构建目标](https://github.com/vercel-labs/agent-browser/blob/v0.43.0/scripts/build-all-platforms.sh)。npm 核心包包含技能资料，平台二进制由 `@agent-browser/cli-*` 包提供；本项目只发布 Linux glibc 两种架构和 Windows x64，不在运行时执行 npm 安装脚本。
- [Playwright 官方系统要求源文件](https://github.com/microsoft/playwright/blob/main/docs/src/intro-python.md)；[1.62.0 PyPI 文件](https://pypi.org/project/playwright/1.62.0/#files)。
- [Selenium Manager 文档](https://github.com/SeleniumHQ/seleniumhq.github.io/blob/trunk/website_and_docs/content/documentation/selenium_manager.en.md#alternative-architectures)；[4.38.0 平台检测源码](https://github.com/SeleniumHQ/selenium/blob/selenium-4.38.0/py/selenium/webdriver/common/selenium_manager.py)。
- [Chrome for Testing 平台](https://github.com/GoogleChromeLabs/chrome-for-testing#supported-platforms)；[157.0.8103.78 清单](https://github.com/GoogleChromeLabs/chrome-for-testing/blob/gh-pages/157.0.8103.78.json)。
- [Python 可搬移构建](https://github.com/astral-sh/python-build-standalone/releases/tag/20250529)。下载时同时核对上游 `.sha256`。
- [Node 24 系统要求](https://github.com/nodejs/node/blob/v24.x/BUILDING.md#platform-list)；[DSH](https://github.com/deepseek-ai/deepseek-harness)。

## 实际验证边界

当前是 Debian 13 x86_64，不是 UOS ARM64。架构选择、错误 ELF 拒绝、旧系统浏览器配置、驱动不匹配、全部上传校验后再替换附件有针对性测试；Linux 本机双引擎启动通过，ARM64 Python 依赖实际下载成功。

GitHub Actions 用 Windows x64、Ubuntu 24.04 x64、Ubuntu 24.04 ARM64 原生 runner 组装三个包，只检查导入、文件架构和完整性。**UOS 真机、UOS 的 DSH 和默认沙箱智能体任务未通过实测，不能标记完成。**
