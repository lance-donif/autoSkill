## 本版变化

- 接口压测使用 Locust。性能测试支持固定并发、内置集合点，以及持续时间和目标请求数。压力测试按阶段递增并发。两种模式各有报告，沿用 JMeter 5.6.3 的统计口径，可下载离线 HTML。已移除 JMeter `.jmx` 执行入口。
- 仪表盘集中呈现总览、测试用例、执行记录、定时任务和数据管理。总览展示最近一批通过率。测试用例目录可折叠，用例和执行详情展示步骤、请求、响应和断言。
- 用例导出沿用测试用例技能的格式。测试报告 Excel 的首个工作表为带图表的概览，执行详情支持下载 HTML 报告。
- 修复 Linux 离线安装和诊断对 Chrome for Testing 版本的识别。诊断按 Selenium 实际使用的浏览器和驱动核对版本。构建时验证两个 Linux 包的浏览器配置。

GitHub Pages 的交互示例由网站单独提供。
