## 本版变化

- 需求阶段：`project create` 可以先不填地址，直接交付 14 列用例 Excel；`plan write --source-doc` 对同一文档版本和相同内容复用原任务，开发完成后用 `project update --url` 继续执行与回填。
- 项目级多环境：每个项目维护多套环境（地址、变量、默认环境），仪表盘范围栏一键切换，`run --environment` 可单次覆盖；冻结输入记录环境快照，历史结果不受切换影响。
- 输出路径：宿主会话只把最终 Excel 和 Markdown 交付到用户项目目录，录制缓存、截图、执行证据保留在数据目录；同名手工修改文件不会被覆盖。
- Linux 同步与错误归档：`AUTOSKILL_SYNC_DIR` 按内容哈希增量导入通过状态的用例文件（JSON/ZIP），`AUTOSKILL_ERROR_DIR` 按日期、项目和运行归档失败 JSON 与 Markdown；数据管理页可查看和手动扫描。
- Pages 示例：加入开发/测试环境切换、环境编辑和同步/错误目录展示。
