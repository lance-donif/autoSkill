## 本版变化

- 修复 Windows 生成 Excel 报告时的 `[Errno 9] Bad file descriptor`。升级后，在原数据目录运行 `autoskill task-report <报告编号> --retry`，即可从原快照重新导出 Excel、简报和 Bug 清单，无需重跑用例。若工作簿被占用或目录写入受限，失败回执会给出阶段和系统错误码。
- 设计任务先交付完整的 14 列设计表初版，再逐行执行。最终工作簿、简报和 Bug 清单可按同一任务核对。用户已编辑正式工作簿时，回填会保留该文件并提示冲突。
- 录制截图提供会话内文件引用、尺寸和 SHA-256，方便核对复制到工作区的图片。可选的回放截图保存或读取失败时，回执会记录原因，文本断言、执行结果和报告仍可查看。

原生 Windows Server 已验证直接调用、本机 HTTP 桥、Windows PowerShell 5.1 和 PowerShell 7。Windows 11 上 DSH Desktop 0.2.2-rc.5 的原生文件卡仍待现场验收。[Windows 验证记录](https://github.com/lance-donif/autoSkill/actions/runs/44664318058/job/136049794277) · [问题跟踪](https://github.com/lance-donif/autoSkill/issues/4)
