## 本版变化

- 手机上打开仪表盘时，顶部导航从首帧起就占好位置。在 DSH 中打开嵌入式仪表盘时，页面直接使用嵌入布局。
- 打开测试用例页时，目录栏和工具区会先占好位置，文件夹列表加载后，正在查看的内容保持在原处。
- 持续集成用 Chromium 测量本地仪表盘和 GitHub Pages 预览的累计布局偏移（CLS），覆盖桌面与手机视口的总览、用例列表和性能报告。布局诊断记录可从 GitHub Actions 下载。
