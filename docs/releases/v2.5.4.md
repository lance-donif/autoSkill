## 本版变化

- 在 GitHub Actions 新增可手动运行的 Windows 离线包诊断。可以按已发布版本检查浏览器启动、工单回放与报告恢复，也可以在固定的 v2.5.3 离线包上对照两种 Selenium Cookie 清理方式。
- Cookie 清理实验的两组工单回放使用独立的数据目录，避免报告恢复时争用同一个暂存文件。诊断运行会保留各组回执、进程记录与超时栈。

v2.5.3 的 Windows 离线包验收曾在 Selenium 启动时超时。两种 Cookie 清理方式在会话隔离实验中均有过超时，本版记录该已知问题并提供复测入口。[离线包验收记录](https://github.com/lance-donif/autoSkill/actions/runs/44773110521) · [Cookie 清理对照记录](https://github.com/lance-donif/autoSkill/actions/runs/44781135609)
