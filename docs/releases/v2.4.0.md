## 本版变化

- 在 DSH 输入 `/autoskill-use`，即可在对话中设计、执行和迭代用例。空会话会显示加载提示。用户要求多智能体协作时，父会话分工，执行方返回运行编号和正式报告。
- 用 `record start <项目> --reuse <用例编号>` 在同一可见标签页执行已保存的前置用例，验证通过后继续录制。新用例保存前置版本和内容哈希，后续回放可重建相同的页面状态。
- 可复用用例支持按业务目录搜索和手动运行。切换 DSH 面板时导航高度保持稳定。浏览器默认可见，并沿用用户明确选择的窗口偏好。
- 对话交付同一报告的 14 列 Excel、Markdown 简报和 Bug 清单。精简后的技能入口在相同运行绑定下从 59,655 字节减至 37,180 字节。

在 Linux DSH 与 Bootstrap Accordion 的实测中，子智能体依次复用两个固定版本，五项检查通过。随后从原目录手动回放同一用例，一次点击完成，新增模型调用为 0。Windows 与统信 UOS ARM64 的真机功能验收仍待进行。[DSH 协作与链式回放验收](https://github.com/lance-donif/autoSkill/blob/v2.4.0/reports/DSH首轮协作与链式回放验收.md)
