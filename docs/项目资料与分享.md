# 项目资料与分享

在侧边栏打开「项目资料」，选择项目后，可查看「知识库」「用例文件」「报告」和「分享与导入」。没有用例的项目也可以先维护知识库。

## 一个数据目录，按项目归档

所有资料仍保存在同一个 autoSkill 数据目录。每个项目的常用资料分开存放：

```text
autoSkill-data/
  projects/<项目标识>/
    knowledge/       知识库原文件
    testcases/       页面、接口用例原文件
    reports/         新生成的测试报告、简报、Bug 清单与冻结快照
    domain/          需求来源、工作流、原生资产和文件夹组织的版本历史
  .local/           本机运行索引、凭据、登录态与执行证据
```

知识和用例页面读取的是项目原文件，没有额外复制一套可编辑资料。新任务报告保存在 `reports/<报告标识>/`；项目汇总保存在 `reports/project-summary/`，文件夹 Excel 导出也保存在 `reports/`。

旧报告继续从原位置读取，保留当时的文件、快照和校验值。资料页将旧报告标为「历史原件」；导出项目资料时一并收集，不会把旧的失败记录改写成当前通过。

## 知识库

选择「新建知识」可创建 Markdown、文本等知识文件，文件名可以包含子目录。文字文件支持查看、编辑、下载和删除。保存会核对读取时的文件版本；其他任务已修改同一文件时，页面会提示重新读取，不覆盖对方的内容。

## 三种导出用途

| 导出 | 用途 | 内容 |
| --- | --- | --- |
| 导出全部项目资料 | 归档、交付，或后续上传资料 | 当前项目的知识、用例、报告、领域版本和文件 SHA-256 清单；旧报告也会归入报告分类 |
| 项目分享包 | 在另一台 autoSkill 导入项目 | 项目原文件、版本来源及报告附件；可选择加密携带项目引用的本机凭据 |
| 数据管理 → 导出全部数据 | 完整备份或迁移运行环境的数据 | 全部项目、运行索引、所有历史和证据、凭据、登录态及设置 |

项目资料包和项目分享包不会将另一个位置的历史附件当成本机当前版本已通过的证据。需要恢复完整运行历史时使用「导出全部数据」。程序包和执行器另行安装。

## 分享与导入

在「分享与导入」中生成项目分享包，再点击下载。也可以选择完整程序包；完整包包含已保存的凭据和登录态，不需要另设加密口令，随包运行时是否齐全以生成结果为准。

导入项目分享包时，可以在浏览器选择 ZIP 上传，或填写运行 autoSkill 服务的电脑上的 ZIP 路径。已有同名项目默认保留，页面显示未导入原因；选择「替换本机已有同名项目」后才会替换。带加密凭据的项目包可以同时填写解密口令。

导入后，项目资料可查看、用例可继续运行；实际验证结论仍由当前环境中的执行证据确定。
