# 一个文件夹保存全部数据

先读取 `autoskill data status`，确认本任务实际使用的数据目录，不能按安装目录猜测。默认目录是 Windows `%USERPROFILE%\autoSkill-data`、Linux/UOS `$HOME/autoSkill-data`；DSH 的 `workspace` 配置或 `AUTOSKILL_WORKSPACE` 可指定位置。

程序更新时，先让当前任务完成并停止旧程序，换上新程序，再以同一个数据目录启动。DSH 需要重新加载插件模块或重启，才能使用新代码与新页面。此流程不调用升级脚本，不复制数据到每个版本的安装目录。

旧版首次迁移通过内置数据管理界面或 `data import <source> --target <空目录>`。目标不能与来源相同，不能覆盖已有数据；原来源保留。读取操作回执、核对用例、运行记录和报告后，再将宿主的数据路径指向目标并重启。导入成功与启用目标目录是两步，不得混写。

分享整套数据用 `data export --out <完整数据.zip>`。也可以在停止 autoSkill 写入后，使用文件管理器压缩整个数据目录；必须包括隐藏的 `.local` 和根目录的 `data-root.json`。数据文件夹包含项目、知识、用例表、历史执行、原生资产、录制草稿、截图、Excel/Markdown/Bug 报告、凭据、登录态、设置、工作流和调度记录。项目级 `pack` 仍用于资产交流，不等于完整数据副本。

复制的进程号、浏览器连接或旧租约不是本机存活进程的证明；不能据此杀进程或重播未知业务操作。旧证据与原始哈希应原样保留，通过明确路径映射读取新位置，不能批量替换历史文件里的路径后重新计算哈希冒充原证据。第三方工具的安装与宿主模型配置由各自环境管理，不随 autoSkill 数据文件夹安装。
