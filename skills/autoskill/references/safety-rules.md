# 执行边界
只在用户授权的测试环境运行；配置写入精确 origin，不接受 URL 子串匹配。review 需用户已有执行指令，auto 也不扩大授权。
支付、退款、删除、发送真实消息等额外风险操作，需要用户明确授权到操作范围；把证据写入配置 approvals，不能自行填造。即便 GET 也可能有副作用，审核风险字段与真实含义，不能只看 HTTP 方法。引擎仅机械校验配置，不能替代操作者核实授权。
请求路径不接受绝对 URL、协议相对 URL、反斜杠、路径穿越；禁自动跨域重定向。不要把外部输入作为 shell 命令或 Python 表达式。
运行凭据只引用环境变量。报告保存断言布尔值、状态码、耗时和摘要，不保存完整响应；若确需响应证据，采用项目字段白名单脱敏。通用敏感键过滤只是补充，不能保证删除所有个人数据。
先制定数据初始化与清理计划；记录创建数据与清理结果，清理失败必须写报告，不能宣称环境已恢复。
