# Python 代码审查、修复与验证报告

本轮由 6 个新建、无历史上下文的子智能体完成：3 个分别修复接口执行、浏览器与页面、状态与交付；另 3 个独立检查接口流程、真人操作路径、仓库与验证工具。主智能体协调边界、核对证据和提交。查看、搜索、规则和验证调度均通过 Python，复用入口已纳入源码。

结论：已复现的问题完成修复；所列最终验收通过。没有使用远程模型、真实账号或付费调用。本报告不声称模型准确率提高，也不把一次本地通过推广为所有环境稳定提升。

## 用户能感知的修复

| 问题 | 修复与实际证据 |
| --- | --- |
| 首次打开页面等待辅助接口，主内容一直空白 | 主视图与运行环境信息并行加载，执行按钮仍等待已保存偏好。修前慢 status 下 5.0566 秒主内容为空；修后开发侧 20/20 次出现真实内容，597–1223 毫秒。独立侧慢 settings/status/revision 分别 647/506/533 毫秒；这些是受控场景结果。 |
| 登录返回的令牌在 Cookie 中使用，生成接口时丢失认证关联；合法模板无法保存 | 唯一来源关联提取值、依赖和 Cookie 模板；Set-Cookie 使用 HTTP 会话，混合来源按 URL 作用域合并。来源不明确则保留未验证说明。独立编译、保存和真实 HTTP 流程通过。 |
| 删除返回成功，但缺少与查询确认的明确关联 | 显式后置检查进入同次冻结运行，单选动作自动包含相关检查；校验实际请求顺序、独立断言、输入、版本及原始 attempt。失败、取消或缺证据不发布；保留既有 204/205 协议契约。 |
| 相同功能预期以数组/换行文本表示时被误认为不同 | 只统一已有的文本展示语义，技术断言和值保持严格；真实 HTTP 验证后可正确关联功能预期。 |
| 等价 Excel 因导出时间变化产生不同字节 | 固定新文件时钟、逐项核对 ZIP 内容；等价旧文件保留原字节和时间。历史失败、冻结报告、初始表格保留。 |
| 后置结果或别次执行可能被错误关联为当前证据 | 检查同 run、实际 attempt、完成顺序和冻结范围。修改后置预期后，当前通过失效，旧运行事实仍保留。 |
| 业务定位不唯一时只返回难懂的 XPath 错误 | 对已确认的业务歧义给出清楚提示；普通 XPath 与显式数量断言保持原行为。 |

同时保留并验证仓库已有的用例交付与页面简化改动：先生成完整 14 列 Excel，再执行、回填同一任务原表；只发布验证通过的 UI/API 候选，失败仍留在报告。用户无需去页面新增任务或填写技术数据。

## 首次失败保留

- v1 独立 API 为 10/12：两处把结果数据库落库顺序当作外部请求顺序。原请求记录已证明删除先于查空；修正测试为完整 HTTP 顺序、结果唯一性和 attempt 时序，保留发布与历史证据断言后，v2 为 12/12。
- v1 用户验收为 4 通过、1 失败、2 错误：验收临时路径超过 Chromium Unix socket 限制，合成候选还引用了未登记需求。仅修私有临时目录和真实需求登记，未降低 5 秒/1 秒时限或业务预期，v2 为 7/7。
- 两处旧 UI 按钮选择器与一个旧 capture 测试桩已按实际产品契约修正，完整失败项复验通过；没有为迁就测试放宽产品行为。
- 开发侧首次取消测试曾失败，随后 4 次通过，但首次原因尚未确认。本轮不将其列为已证明修复或稳定提升。

v1 清单共 638 个文件，摘要 `e2fa3df5a9bc5c54b45b02d4a14eae31820a36faf248a09e189cacddabea42b3`。v2 摘要 `44a8eab85962ba77e525e0b0dcc3a2c261ae9e859bffa0c10a11226d35293a94`；仅两份独立测试夹具不同，其余 636 文件相同，产品字节完全相同。各验收前后均核对清单，未发生源码漂移。统一 CI 未因夹具修正重复执行，仅复验受影响测试并检查其 Ruff。
