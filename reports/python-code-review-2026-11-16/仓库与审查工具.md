## 本域改动与审查结果

- `scripts/code_review.py` 提供可移植的 Python 文件清单、带行号查看、搜索和规则入口。搜索优先调用已有 rg，缺少时回退 Python；空匹配、错误正则、缺工具、越界文件和规则异常均有明确结果。规则异常不会计为通过。
- `scripts/validate_review.py` 按显式 suite 或测试文件调用既有 Ruff/Biome/unittest/Node，使用列表参数与 `shell=False`。它不替代或放宽 lint；保留原退出码、版本、日志、超时和跳过数量，输出目录可在仓库外，数据与会话隔离。非空输出目录不会覆盖，POSIX 超时清理该项进程组。
- `repository` 规则用 Python AST 核对本地导入闭合，并检查插件相对导入、包导出与发布版本、CI 脚本/测试引用以及唯一的项目依赖版本锁定。回归用删除本地模块、错版本、缺失测试及重复 pin 等实际结构变异验证其失败行为。
- CI 改为复用该验证入口，保留原工作流、知识和 host 契约范围；补齐 Starlette/Pydantic 的项目既有版本锁定，保留检查日志和摘要。顶层导入依赖扫描覆盖 109 个模块，未发现所选契约还缺必需安装项。
- SDK fixture 优先采用本次 `AUTOSKILL_VALIDATION_PYTHON`，避免显式 Node 回归意外选用另一个解释器。host adapter/backend 静态审查未发现需要修改插件的确定行为缺陷。
- 公开 skill、命令与执行文档同步 API 显式后置检查、Cookie 变量、同次运行与发布集合、功能预期数组的保真比较；API 实现作者已复核措辞一致。
- lint/release YAML 及三个内嵌 Python 块可解析。现有 release 门禁在新构建的 Linux x64 runtime 上执行指定浏览器与证据测试，禁止跳过，发布依赖构建成功；本次未构建发行包，不据静态审查声称平台设备验收。
