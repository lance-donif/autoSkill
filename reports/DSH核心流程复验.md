# DSH 核心流程复验

2026-11-17。基线为 `bea4a41`，工作分支为 `work/dsh-core-flow`。在 Debian 13 x64 的官方 DSH Web `0.2.2-rc.1` 中加载源码插件，使用 `workspace-write`、独立数据根和本机 Ticket Desk 合成站点。浏览器为 Chromium `156.0.8078.79`，Playwright 和 Selenium 均通过实际启动检查。[Linux 源码部署](../docs/Linux-DSH.md)

## 前后端修复

- 内嵌和窄屏仪表盘把视口剩余高度留给页面内容。功能导航顶栏保持单行，下拉菜单高度由视口决定，分组展开后在菜单内滚动。
- 普通回放的全量、未通过和单条重跑沿用原任务会话、用例表、输入和独立 API 模式，从当前保存定义生成新的运行。早期无冻结清单的记录仍可重跑。
- DSH 工具卡按原请求编号查询回执，显示返回的运行状态和对应报告入口。两次丢失回执可独立找回，卡片识别已结束与已删除的运行并收起取消操作。
- 运行页即时展开新到达的未通过结果。在同一报告中手动收起后，后续刷新尊重该选择。
- 匿名接口的状态码与明确业务预期不一致时，记录实际断言失败。托管登录依赖收到意外的 401 或 403 时沿用既有登录接续和重试行为。

## 回归与验收范围

Ruff、Biome、7 项项目约定和 20 项审查工具测试通过。另通过 181 项 Python 后端和契约测试、53 项仪表盘和报告回归，以及 82 项 Node 测试，其中包括官方 DSH SDK 的本机工具和会话测试。以上测试均无跳过。新增的导航回归覆盖 656 和 225 像素嵌入视口及 390 像素独立视口。编辑器旧测试已按现有「可复用用例」标题校准，原草稿保护和路由断言保留。

真实 DSH 父子模型会话按本轮约定记录为阻塞，当前环境没有配置历史模型网关凭据。浏览器截图、Excel、回执和检查结果见交付件 `autoSkill-dsh-evidence.zip`，测试范围为本机合成数据。
