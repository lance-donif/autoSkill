# DSH 自测覆盖清单（执行计划）

此文件是本次真实 DSH 验收的执行计划，**其中项目尚未因列入清单而通过**。`tests/test_load_dashboard.py`、`tests/test_dashboard_features.py` 和其他普通 Chromium 测试是内核与独立仪表盘证据，不能替代真实 DSH、插件加载、宿主模型调用与技能执行证据。

## 环境和执行记录

- 使用独立 DSH 配置、独立端口与独立 autoSkill 数据目录，例如 `/workspace/scratch/autoskill-dsh-acceptance/data`。不导入或覆盖用户现有数据。测试站点、资料和账号均为本机合成数据。
- DSH Web 实际加载 `/workspace/autoSkill` 本地插件；由其启动仪表盘，确认 iframe URL、会话卡和工具来自该插件实例。记录 DSH、插件代码、Python、Node、浏览器实际版本与来源。
- 当前开发验证 Python：`/workspace/.venvs/autoskill-validation/bin/python`。Chromium：`/home/agent/.cache/ms-playwright/chromium-1234/chrome-linux64/chrome`，151.0.7922.34。此处仅说明开发环境，不能替代 DSH 进程实际继承的运行时检查。
- `scripts/run-dsh-linux.sh` 默认找 `../autoskill-linux-tools`，也支持 `AUTOSKILL_DSH_TOOLS`。安装及插件注册见 `docs/Linux-DSH.md`。本轮检查时 `dsh` 不在 PATH，需由真实 DSH 验收执行者准备。
- 用户提供的外部模型使用 `deepseek-v4.1-flash`；密钥只在独立私有配置/进程中使用。截图、HAR、请求日志、命令行和报告均不记录密钥原文。验收结论应基于实际调用结果，不能用本地协议模型替代远程模型。
- 每项记录操作路径、输入fixture、结果、运行/工作流/资产ID、截图、逐条断言与输出文件。区分 `通过 / 失败 / 阻塞 / 尚未执行`；宿主送达不等于工作完成，缺少第三方工具不算业务通过。
