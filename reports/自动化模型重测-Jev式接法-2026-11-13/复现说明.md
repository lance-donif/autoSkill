# 重测证据与复现说明

本包是外部宿主实验，不是已部署的 autoSkill 模型功能。原生产源码没有修改。

## 已执行范围

- 三个本地模型，每个执行原始单题、单题加历史、分层选择、主模型规划后局部选择四种配置。
- 每配置 16 轮：8 种场景 × 英文/中文，各一种固定候选排列；三模型共 192 轮。
- DeepSeek 逐步选择 16 轮，一次规划后直接回放 16 轮，共计 224 轮正式模型/规划试验。
- 当前协议下的脚本控制 16/16；更早的预检控制单独保存在 preflight-initial，不算正式模型试验。
- 14 个正向任务和 2 个缺失处理场景分别统计。没有把失败或模型自报完成改为通过。

## 证据目录

- `证据/protocol.json`：问题文本、模式、固定范围、参数、源代码 SHA 和实验边界。
- `证据/plans/` 与 `plan-manifest.json`：16 份实际 DeepSeek 规划及其摘要、时长和哈希。
- `证据/results/*-episodes.jsonl`：每轮结果、每次实际动作、输入/输出、实际观测和断言。
- `证据/results/step-events.jsonl`：调用前、决策后、动作后的即时事件。
- `证据/results/api-events.jsonl`：不含认证头的 API 请求和必要响应摘要，含空正文/格式错误的记录机制；本轮没有执行阻塞。
- `证据/results/screenshots/`：计时结束后采集、遮罩密码字段的真实页面截图。Excel 的截图链接指向此目录。
- `证据/results/readback-verification.json`、`workbook-validation.json`：执行轨迹及 224 条 Excel 的读回检查。
- `证据/results/weight-verification.json`：本地权重与上一轮固定 safetensors 的 SHA 一致。
- `证据/src/`：源代码保存为 `.py.txt` 以区分报告数据与产品可执行文件；复现时恢复为 `.py`。
- `证据/reference/`：执行环境、版本、模型工件、官方页面快照及来源。

## 怎样解释时间

浏览器执行从导航开始，包含观察、推理/API、动作、等待和最终验证。模型加载、浏览器启动、上下文创建及结果截图不在此区间。

规划每个任务只请求一次，并被三种本地配置和直接回放复用。报告单列真实执行时长与规划时长；“规划＋执行”是两项实测的算术和，不是每次重新请求网络所得的墙钟时间。它不能冒充多次实际 API 调用或账单。

多问题是本地 SDK 批处理，不保证共享一次编码。前向次数与问题数分开计数；无本地推理的步骤单列，不能把唯一候选由代码处理的效果归给模型。

## 保留的边界

没有运行 Jev 云模型或完整插件，也没有测试 Selenium WebDriver、完整 DSH 会话、生产网站或专项微调权重。这里只迁移部分分工和决策机制，执行相同有限候选任务。

当前协议不启用运行时回退；规划是前置调用。主模型在规划时已看到全量候选，直接回放能利用这些 action_id；小模型只能读取原子指令，不读取 action_id 或评测正确答案。未知控件在后续页面才出现的情况还未覆盖。

原生 Excel 渲染视觉检查未完成；工作簿通过保存后读回及项目 14 列规范校验。所有旧测试结果独立保留。
