# UI 用例弱网对照验证

2026-11-13，使用本轮 DSH 中已经通过的 `TC-UI-MIXED` 修订 2，在正常网络及两档弱网下运行。Playwright 和 Selenium 每档连续执行 3 次，共 **18/18 通过**；每次只有 1 次实际尝试，没有重试。未修改用例、业务预期或超时。

## 结果

表中时间是用例执行耗时，包含页面加载、动作和断言；不含浏览器启动及报告导出的额外时间。原配置始终为**单步操作 3 秒、页面加载 10 秒**，不是整条用例 3 秒。

| 网络 | 延迟 / 下载 / 上传 | 引擎 | 通过 | 三次耗时（秒） |
| --- | --- | --- | --- | --- |
| 正常网络 | 不注入延迟或限速 | playwright | 3/3 | 4.229 / 4.003 / 4.041 |
| 正常网络 | 不注入延迟或限速 | selenium | 3/3 | 4.662 / 4.624 / 4.598 |
| 一般弱网 | 300 ms / 1.5 Mbps / 750 Kbps | playwright | 3/3 | 4.681 / 4.668 / 4.724 |
| 一般弱网 | 300 ms / 1.5 Mbps / 750 Kbps | selenium | 3/3 | 4.930 / 5.026 / 5.064 |
| 严重弱网 | 800 ms / 400 Kbps / 200 Kbps | playwright | 3/3 | 6.058 / 6.187 / 5.851 |
| 严重弱网 | 800 ms / 400 Kbps / 200 Kbps | selenium | 3/3 | 6.331 / 6.477 / 6.401 |

严重弱网下用例执行时间上升到约 5.85–6.48 秒，但两个引擎均在原配置下完成填写、双击保存和结果断言。没有网络超时、定位失败或业务断言失败。

## 网络确实生效的证据

- 限速使用独立 HTTP 字节转发代理；上传、下载各使用全局字节预算，延迟分在上行与下行各一半。未对操作增加固定等待，未修改任何产品执行代码。
- 同一个固定 Chrome 启动包装器强制本地页面也经过代理。每轮启动全新浏览器和上下文；目标页未注册 Service Worker；每轮主文档、两层 iframe 和同名干扰 iframe 都出现真实代理请求，避免缓存或只限主页面造成假弱网。
- 真实 Chrome 额外完成 128 KiB 下载、64 KiB 上传与小请求校准，上传、下载内容逐字节或 SHA256 一致。校准与正式用例分开统计。
- 一般弱网：小请求约 334 ms，下载约 1.447 Mbps，上传约 740 Kbps；严重弱网：小请求约 849 ms，下载约 396 Kbps，上传约 199 Kbps。
- 正式严重弱网中的每层文档都有约 850–883 ms 的代理耗时。浏览器进程参数真实观察到 headless 和强制 loopback 代理，未弹出窗口。
