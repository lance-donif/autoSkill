# 通用 Skill 能力补齐与内部闭环验证

日期：2026-11-12。基线为远端 `e0b26b0`（包含 `06f37f2` 的用例表、可见窗口、同站项目、验证码与 CRUD 改动）。本次仍使用完整 Chrome/Chromium；没有换成 Headless Shell。

autoSkill 是通用命令行 Skill，DSH 插件仅注册 Skill、启动仪表盘。本报告中的开发侧验证不等于 DSH 默认沙箱或 UOS ARM64 真机验收。

## 交付能力

| 场景 | 实现及内部闭环 |
| --- | --- |
| 浏览器操作 | 增加历史导航、焦点、拖放、嵌套 iframe、预备弹窗策略、脚本、键盘/鼠标、滚动、等待、上传/下载及设置；同一份录制走 Playwright、Selenium 和两类独立脚本。读取与诊断不冒充业务断言。 |
| 第三方原生命令 | `capabilities` 与 `browser help` 无需启动浏览器即可发现能力。可执行、可录制、可回放、可导出分别标注；不支持移植的突变明确保留为 `native_step`，运行显示 Blocked，导出说明原因。不会丢掉一步后报告通过。 |
| 内部工单系统 | 补上编辑、状态更新、取消删除和确认删除；接口提供 POST/GET/PUT/PATCH/DELETE、角色校验、原子更新和删除后不存在检查。 |
| HTTP CRUD | 真正请求本机工单服务器；末条用例触发完整登录/创建/读取/替换/修改/删除/404 前置链，验证变量关联、数据库结果和业务数据回到初始状态。 |
| SSE / AI 长回答 | 分开收集推理与答案，等待 `[DONE]` 或明确配置的终止条件；支持总预算、首事件/空闲预算、取消及首事件/文本延迟断言。半截回复或提前断流不能通过。 |
| WebSocket | 支持有序发送/接收/JSON 字段断言及明确终止条件；本机完成 CRUD 会话。不同协议不能伪装成普通 Postman 请求。 |
| WebSocket 音频 | 项目内 PCM/WAV 素材分片发送，覆盖 base64 和二进制；接收音频、断言帧数/字节数/首音频延迟，保存私有 WAV 证据。两条用例的同名输出分目录保存，不覆盖。 |
| 网页麦克风 | 显式配置测试 WAV，实际调用 getUserMedia 和 WebAudio 测量非静音波形，验证停止轨道；完整跑录制、双引擎及双独立脚本。使用合成测试音，不采集用户真实麦克风。 |
| WebRTC | 保留两端真实 RTCPeerConnection、双向音频 RTP、DataChannel、延迟 SSE 回复和停止清理断言；当前机器的浏览器管理策略使本机 ICE 连接受阻，不能记通过，见下文。 |
| 断言等待 | 项目/单步独立超时，支持持续稳定时间。真实页面首 token 很快出现，6 秒后短暂假完成，随后才完成；验证默认短超时被显式长预算覆盖，短暂完成不能误判。 |
| 知识沉淀 | `knowledge add/search/show` 显式保存事实，并关联真实 case/run 证据和当时状态；成功运行、失败结果、页面或模型文本不会自动成为已确认知识。 |
| 大用例库 | 实际构造 5000 条规范用例、5000 行 Excel 与 100 篇长知识；默认仅 30 条摘要、最多 5 条知识片段，支持筛选、翻页和单条展开。生成的两个 Skill 也不内联整个用例库。 |

独立 UI 脚本不能静默省略 API 前置；这类混合链通过 `autoskill run` 执行。上传和麦克风素材需使用项目脚本导出并携带 `assets/`，仪表盘单 `.py` 下载会明确说明。Postman 导出只接受完整的纯 HTTP 链。

## 验证环境与证据

Debian 13 x86_64、Python 3.12、仓库 `.venv`、agent-browser 0.42.0、系统 Chromium/chromedriver 156.0.8078.79。浏览器功能测试使用 headless 模式和临时数据目录，正常产品的可见窗口默认值保持不变。

测试入口：

```sh
.venv/bin/python -m unittest discover -s tests -p 'test_*.py' -v
node --test tests/plugin.test.mjs
```

全量结果与原始日志在最终回归后补入本节。主要可复核测试包括：

- `test_browser_capabilities.py`：真实页面的录制、编译、双引擎与双独立脚本，含 CRUD、嵌套框架/标签页、输入、弹窗、文件及诊断产物。
- `test_ticket_desk_ui_crud.py`、`test_ticket_desk.py`、`test_runner.py`：随包工单页面与接口的真实 CRUD 和登录依赖。
- `test_streaming_protocols.py`、`test_protocol_cli.py`、`test_protocol_runner.py`：真实 localhost HTTP/SSE/WS、音频文件、结果落库、每用例证据隔离和显式知识沉淀。
- `test_realtime_browser.py`：实际麦克风波形和真实 WebRTC 连接；受阻的测试明确记录 skip/Blocked 原因。
- `test_context_scale.py`：大用例表、Skill 文本大小、知识分页与证据关联。
- `test_runner_capability_boundaries.py`、`test_postman_protocols.py`、`test_script_downloads.py`：不漏选原生步骤、不遗漏前置、不伪造可移植导出。

## 尚未验证及环境限制

- 系统 `/etc/chromium/policies/managed/misc.json` 设置了 `WebRtcIPHandling=disable_non_proxied_udp`，并限制音视频、定位等权限。真实 WebRTC 测试无法产生可连接的本机 ICE 候选；未修改系统策略，未用模拟连接代替。WAV 麦克风波形与 WebSocket 音频成功不等于 RTP 已通过。
- 没有在真实外部 ASR/TTS/实时模型上确认识别准确率、语义正确性或服务端音频格式；合成音回环只证明传输和测试机制。
- 没有在 DSH 默认沙箱里重新完成真实智能体任务；模型网关仍受当前云环境代理限制。插件契约测试和本机桥接测试不能代替这项验收。
- 没有 UOS ARM64 或 Windows 真机的新一轮功能验收；本次 Linux x64 结果不能外推到它们。
- 本次能力改动尚未发布到历史 v2.1.0 离线附件；旧包的大小、摘要和验收边界保持原记录。
