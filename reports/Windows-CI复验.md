# Windows CI 复验记录

2026-11-12。v2.0.2 的 Windows 包运行时 2551 项校验一致，doctor --launch 两种浏览器启动成功；完整回归 118 项，失败 2 项、跳过 2 项 Linux 专属测试，未发布。原始证据在 `evidence/releases/v2.0.2/`。

两处修正：

- 缺失弹窗测试原来把初始导航和等待弹窗共同设为 0.3 秒，Windows 在页面打开阶段就超时。改为 5 秒，仍断言等待不存在的弹窗明确失败且没有切错页面。
- 随附原版 TodoMVC 在 window.load 中初始化路由和计数；页面控件可见不等于初始化结束。页面回放测试补充实际就绪前置断言（计数已初始化为 0），再执行原有输入、按键和业务断言；没有修改上游页面、删掉断言、改期望或自动重试。
- 测试 HTTP 服务忽略浏览器关闭连接时正常发生的 ConnectionResetError，避免将断开空闲连接打印成应用错误。

Linux 针对性复验：页面回放 14 项通过（29.118 秒），缺失弹窗测试通过（14.822 秒，覆盖两种引擎）。v2.0.3 的 Windows 完整回归与发布以 `release-status.json` 及后续 CI 证据为准；此处不提前写成通过。

v2.0.3 的两个前述失败已消除；完整 Windows 回归仍有 1 项失败：多弹窗用例的独立 Selenium 脚本在打开初始页后找不到按钮，内置两种引擎回放都通过。详见 `evidence/releases/v2.0.3/`。本次为独立脚本增加实际页面地址、标题和加载状态诊断，并提高本机测试 HTTP 服务的连接队列容量；v2.0.4 先要求三次多弹窗/独立脚本专项全部通过，再进行全量回归。Linux 专项复验通过（8.410 秒）。Windows 结论仍以后续 CI 输出为准。
