# 独立黑盒验收任务

测试边界：只使用公开 CLI、公开 HTTP API、公开使用说明和本目录自产数据；不读实现、内部测试、其他 Agent 输出、凭据或主模型配置。被测业务是本地 HTTP fixture，独立需求是返回 `ready`，延迟场景用于观察执行阶段与取消。

每轮从独立数据目录和独立 session 开始，同一套任务在复验时重复。业务失败、执行失败、未执行、证据缺失、导出失败分别记录。

| ID | 验收任务 | 独立预期 |
| --- | --- | --- |
| BB01 | 公开入口和隔离 workspace | 入口可运行；仅操作当前隔离目录 |
| BB02 | 创建项目、读回上下文 | 项目身份稳定，初始无伪造用例或运行 |
| BB03 | 用公开流程保存通过与失败用例 | 断言独立于被测实际值；失败保留原预期和实际 |
| BB04 | 执行通过用例 | 主状态体现执行阶段，业务结果、性能、证据、交付独立可读 |
| BB05 | 执行业务失败用例 | 执行完成且业务失败；不把断言失败包装为工具崩溃或执行失败 |
| BB06 | 活动运行状态查询和取消 | 在线变化目标 1 秒内；取消后终态稳定、无虚假通过 |
| BB07 | 失败后重试 | 保留旧运行/尝试；新尝试不覆盖旧失败与证据 |
| BB08 | 创建工作流并领取/提交公开任务 | 按返回 schema 操作，阶段、业务判定和实际证据相符 |
| BB09 | 工作流暂停和恢复 | 已有失败不被改写，恢复不重复业务副作用 |
| BB10 | 新工作流周期与历史隔离 | 新周期不借用旧结果，旧周期状态与证据稳定 |
| BB11 | 任务报告三文件检查 | ready 仅在 Excel、Markdown、Bug 清单实际存在且哈希一致时出现 |
| BB12 | 报告失败后手动 retry | 仅重新导出相同任务快照，不重新执行；不可公开构造则 Blocked |

判定规则：每个 ID 最终只计一次 Pass/Fail/Blocked；子观察用于解释。公开流程不能构造或环境缺能力时计 Blocked，不猜测通过。CLI 查询/入队 exit 0 仅代表命令成功。

阶段：公开文档与任务设计 → 基线执行 → 汇总原始证据 → 接到通知后相同任务复验。
