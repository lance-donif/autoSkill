# 独立代码审计契约清单

审计范围：/workspace/autoSkill；不修改产品、现有测试或 git；不接收黑盒 Agent 结果。证据仅保存在本目录。基线 HEAD：c116713。

1. 执行阶段是主状态；业务、性能、质量、证据、报告、投递分别展示并有明确枚举/聚合规则。
2. completed 仅表明执行阶段结束，不能被转换为业务 Pass；无断言、观察 oracle、复用登录和缺失证据均不得验证业务成功。
3. 当前周期是默认查询/列表/指标/宿主上下文范围；历史周期和重试记录可显式访问，历史失败不能被后来成功抹去。
4. 同一周期中已见业务、性能或质量失败被保留；聚合不能以部分 Pass 覆盖未完成/未验证分项。
5. 读取状态和 GET 不 claim、执行、推进工作流、生成或重试报告、改变租约/副作用/投递状态；派生状态可以读取既有证据并降级。
6. 后台独立推进确定性阶段、收集完成执行并过期租约；服务/CLI 返回不依赖下一次宿主轮询。
7. 显式租约校验 attempt、token、workflow/cycle、deadline 和 lifecycle；旧提交不可写新 attempt，迟到实际收据只补历史。
8. 操作意图先于外部副作用；未明副作用必须进入调查，禁止自动重放；取消、租约过期和进程恢复不得隐含重跑。
9. 取消与完成并发以原子更新保护；取消请求与已完成结论分离；不以复制 PID 判定或终止本地进程。
10. 缺失/篡改 manifest、attempt receipt、source object 或 artifact 使当前证据失效，派生当前 Pass/满足结论必须降级；历史观察失败仍可显示为历史失败。
11. 报告 ready 需要 Excel、简报 Markdown、Bug Markdown 三者存在、身份绑定、hash/大小和读回验证；宿主上下文同样校验，不直接相信旧 receipt.status。
12. 报告失败只由手动 retry 继续；普通状态读取、后台循环或无关 revision 变化不得再次 capture/render。
13. 手动 retry 只消费同一任务同一周期冻结 snapshot，不能重新执行测试或借用当前/另一任务结果；旧报告字节/身份保留。
14. 报告生成状态与宿主投递状态区分，host accepted/present 不等于业务验证或执行结束；unknown 投递先查实际回执再重试。
15. 在线可见前台<=1秒同步，包括原本空闲后由外部触发的变化、跨页面状态和宿主任务卡；修订号覆盖证据和报告失效。
16. 一次视图的一切计数/列表/派生结论使用一致范围和快照；分页游标对修订/周期变化有明确拒绝或实时契约。

分类规则：确认缺陷=可复现或确定代码路径；待测=尚缺实际证据/最终改动；正确行为=代码与独立检查均支持。基线发现不自动等于最终缺陷，最终稳定 diff 需逐项复核。
