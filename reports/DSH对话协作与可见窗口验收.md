# DSH 对话协作与可见窗口验收

2026 年 11 月 17 日，在真实 DSH 0.2.2-rc.1 使用 `deepseek-v4.1-flash` 测试 Bootstrap 5.3 第一个 Accordion 示例。父会话与子智能体均使用此模型。浏览器运行在隔离的 Linux X11 桌面，窗口检查记录了 Chromium 进程、窗口映射状态和启动参数。[Bootstrap Accordion](https://getbootstrap.com/docs/5.3/components/accordion/)

## 对话与多智能体

DSH 的斜杠菜单可以选择无参数的 `/autoskill-use`。命令返回成功，向当前会话注入技能说明，下一条对话触发模型并由父会话委派。当前宿主未在对话里显示人可读的加载成功提示。父会话与四个原生子会话的 `todo/write` 事件合计为 0。

| 顺序 | 实际任务 | 回执 |
| --- | --- | --- |
| 1 | 执行子智能体生成 V1 的 14 列设计表，录制、回放和发布两条用例 | `TC-UI-002` 初始展开，`run-70d39f11d8dc` 通过。 `TC-UI-003` 点击 Item #2 后互斥展开，`run-f37a692deb56` 通过。两条均已发布 |
| 2 | 独立复核员核对 V1 用例、Excel 和运行证据，再回放已有 `TC-UI-003`，为 V2 提供前置回归 | `run-52f3d556c630` 通过。该回执先于 V2 子智能体获派 |
| 3 | V2 子智能体引用前置回执，在同一业务目录生成并执行 Item #3 的新增测试 | `run-342b2bc6133d` 通过两条互斥断言，发布 `TC-UI-004`。V2 Excel 已生成并关联该运行 |
| 4 | 独立验收用户在 DSH 的「可复用用例」按目录选择 `TC-UI-004`，点击「运行这条用例」 | `run-fe99ee58497b` 可见回放通过，页面可下载本次 Excel |

最初的只读复核任务与 V2 复核范围重叠，父会话将两项合并。隔离宿主退出时 V2 设计仍在进行。重启后重新打开同一父会话，原 V2 子智能体从已有前置回执继续，完成设计、录制和自动验证。V1 原报告保留两条原始运行，V2 报告记录新增场景及复用来源。

首次录制受中文优先级「高」与执行格式不匹配影响。模型改用 P1 完成了当轮测试。本轮代码补上「高、中、低」到 P0、P1、P2 的转换，原设计文字仍随候选保留。复核还发现 V1 Excel 主表的长录制观察遮住了回放摘要。V2 正式 Excel 的实际结果开头已显示运行编号、通过状态、步骤和断言数。

## 浏览器与交互

- 公开网站实测的四次模型回放与一次手动发起的回放均为可见模式。X11 抓取了加载 Bootstrap 的可见 Chromium 窗口，进程参数中没有 `--headless`。产品默认显示窗口，Linux 缺少图形桌面时会报出受阻原因，用户保存的隐藏偏好和本次显式选项仍可生效。
- 实际 DSH 面板宽 744 px，跨页面和慢请求执行了 13 次高度检查。导航栏总是 49 px，展开菜单总是 464 px，无横向溢出。目标页加载时立即移除来源页的运行控件，并显示「正在加载页面…」。
- 测试用例表与可复用用例以 `Bootstrap / 组件 / Accordion / 展开互斥` 显示目录。切换用例表保留键盘选择焦点。测试用例表用于查阅、下载和追溯，对话负责设计和更新。

## 回归范围

可见 Chromium 仪表盘回归 17 项通过。录制、Playwright、Selenium 和独立脚本回归 15 项通过。Node 宿主检查含真实 DSH SDK，共 82 项通过。设计来源、用例目录、候选交付和 Excel 分项回归通过。后端合成项目另验证了前置登录与过期更新、只维护受影响的 20/100 条用例、版本化知识复用。Bootstrap 复用的是已有用例和本次前置回执，回放引擎直接执行保存的步骤。整轮模型 Token 节省比例暂无对照数据。

附件 `autoSkill-dsh-dialogue-evidence.zip` 包含两轮初始与最终 Excel、真实执行回执、DSH 原生会话事件摘要、可见浏览器截图及回归记录。
