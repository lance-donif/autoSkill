## 多会话的实际验证

`--session <标识>` 或 `AUTOSKILL_SESSION` 为不同任务选择独立浏览器、录制、临时文件与默认用例表。标识原文不作为路径；旧默认命令保持可用。后台转交保存调用身份，并兼容仍在运行的旧服务转交命令。

实际执行了两路 CLI 经本机 HTTP bridge 操作两个真实浏览器：同一站点、同一项目分别处理 alpha/beta；取消甲不关闭乙；并发保存产生不同 UI 编号，得到 2 条 UI 与 2 条 API 用例；UI/API 回放通过，导出的 Playwright 和 Selenium 独立脚本也运行通过。

不同项目的真实 HTTP 请求同时在途，证明任务确实并行；同一个 run 的两个调用只发送一次业务请求。同项目回放仍按共享登录态排队，全局并发默认 2，可通过 `AUTOSKILL_MAX_PARALLEL` 调整。这不是同项目所有回放已并行的证明。

共享凭据、登录态、项目和显式共享 Excel 均有真实多进程测试。Excel 的只读查看不要求创建写锁；失败保存保留原表与权限。
