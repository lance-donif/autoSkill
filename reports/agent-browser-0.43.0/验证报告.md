# agent-browser 0.43.0 升级与重复验证

日期：2026-11-14。项目：`lance-donif/autoSkill`，升级前主分支 `f2f66a0`。

本次将 agent-browser 从 **0.42.0 升至 0.43.0**，适配新版平台包、同步离线技能，并验证快照提示与录制回放。真实浏览器回归 **27/27 通过**；预先固定条件的 30 组大页面配对测试中，新版 **29/30 更快**，配对耗时变化的中位数为 **−17.49%**，三个独立批次均通过门槛。

这一提速结论限定在本机、6000 个具名按钮的静态页面和原生快照调用。没有测量 DSH 完整任务、模型准确率、令牌成本或生产网站耗时，不能据此宣称这些指标提高。此前编排赛马未达到稳定提升门槛的提示方案没有并入本次代码。

## 交付变更

- Linux x64、Linux ARM64、Windows x64 下载脚本固定使用 0.43.0。新版核心 npm 包不再携带所有原生程序，改为下载核心资料和当前平台的 `@agent-browser/cli-*` 包，避免沿用旧脚本后生成缺少程序的离线包。
- 两个平台的构建脚本共用组装函数，核对包名、版本与平台，校验新增原生归档的哈希，并同步许可证。旧版合并归档仍可组装。
- 原生程序发现支持新版 npm 的并列、嵌套及 Windows cmd 入口布局，直接调用匹配的原生文件，不执行 npm 启动脚本。显式路径和随包程序仍优先。
- 离线核心技能的 14 个文件与官方归档一致；重新生成版本和逐文件哈希，清除上游已移除的旧资料。
- autoSkill 技能补充同名、无名控件的 `hint` 用法：提示用于区分当前引用，不是可访问名称或业务断言；稳定定位继续读取 `browser describe`。
- 本机源码的忽略目录及原测试环境运行文件已替换为 0.43.0。去掉显式程序路径后，`paths.agent_browser()` 也能找到新版；二进制未加入 Git。

官方发行说明：[v0.43.0](https://github.com/vercel-labs/agent-browser/releases/tag/v0.43.0)。其中大页面优化为复用一次解析的可访问性树；本次没有在 autoSkill 内重复实现上游算法。

## 真实浏览器功能验证

运行环境为 Linux x64、Python 3.12、Chromium 156 及匹配的 chromedriver。每轮使用独立临时数据，实际驱动浏览器，保留检查的原始失败语义。

| 验证范围 | 重复次数 | 结果 |
| --- | ---: | --- |
| 新录制会话保持同一浏览器、业务 HAR、报告及回放 | 3 | 3/3 |
| 子标签页关闭并把结果返回父页 | 3 | 3/3 |
| target_blank 录制、回放及独立脚本导出 | 3 | 3/3 |
| window.open 录制、回放及独立脚本导出 | 3 | 3/3 |
| 跨域 iframe、开放 Shadow DOM 混合上下文及双引擎回放 | 3 | 3/3 |
| 区域缺失、封闭 Shadow DOM 保持明确失败 | 3 | 3/3 |
| 嵌套 Shadow 引用及 iframe 刷新后重新定位 | 3 | 3/3 |
| 两个真实 CLI 任务通过桥接独立录制、取消、保存、回放 | 3 | 3/3 |
| 同名按钮提示选中指定行，保留真实名称，检查、保存、回放 | 3 | 3/3 |

前八项分三轮运行，新增提示场景另外连续运行三次。另有 **36 项单元与约定检查通过**，覆盖拆分平台包、旧归档兼容、版本与平台不匹配、原生归档篡改、资料路径、程序查找和已有平台打包约定。Ruff、Biome 均通过。

三种平台的官方归档均通过 npm SHA-512 完整性校验，实际完成 agent-browser 组件组装、ELF/PE 架构检查和资料哈希核对。**未构建并运行完整离线发行包；Windows、ARM64、UOS 未做真机验收。**

## 预先固定的快照 A/B 测试

正式采样前完成两按钮的连接可行性检查，未采集性能数据；随后冻结[测试协议](evidence/snapshot-protocol.json)和脚本、源码、两个程序的 SHA-256。旧程序也与官方 0.42.0 归档中的原生文件逐字节哈希相符。

- 三个批次各启动独立浏览器配置和控制目录；每个批次的新旧程序以 CDP 连接同一个页面，顺序执行只读快照。
- 每批 10 组配对，新旧先后交替；每版本每批预热 2 次，预热单独保留、不计入正式统计。
- 每页 6000 个唯一具名按钮；每次都核对全部名称及引用数量。共 60 次正式快照、12 次预热，**72/72 正确**。
- 计时覆盖 autoSkill 原生调用、CLI 及其文件 I/O，排除浏览器启动、预热和测试证据保存。测速期间不并行执行其他测试或下载任务。
- 通过条件：每批配对耗时变化的中位数 ≤ −10%，20,000 次配对重采样的 95% 区间上界 < 0；合并胜率 ≥ 80%，Wilson 95% 下界 ≥ 70%；快照全部正确。

| 批次 | 旧版耗时中位数 | 新版耗时中位数 | 配对变化中位数 | 95% 重采样区间 | 更快组数 |
| --- | ---: | ---: | ---: | --- | ---: |
| 1 | 883 ms | 657 ms | −18.59% | [−32.21%, −12.78%] | 10/10 |
| 2 | 832 ms | 684 ms | −17.62% | [−19.80%, −12.48%] | 10/10 |
| 3 | 840 ms | 702 ms | −16.16% | [−22.00%, −10.76%] | 9/10 |

三批全部通过。合并配对变化中位数 **−17.49%**，观察胜率 **96.67%**，Wilson 95% 下界 **83.33%**。这是固定页面和环境下的重复快照结果，不能解释为跨网站、跨任务的未来提升概率。表中的配对变化来自每组新旧耗时之比，不是两个耗时中位数的比值。

## 维护者下载量

按本次实际下载的压缩归档字节数，旧版核心包为 59,645,044 字节；新版核心包加 Linux x64 原生包为 8,923,004 字节，减少 **85.04%**。Linux ARM64 为 8,407,451 字节，Windows x64 为 8,824,153 字节。

此项只比较维护者获取 agent-browser 依赖的下载量，不包含 Python、Chrome、驱动和 Python 库，也不表示用户最终离线包缩小 85%。
