# DSH 首轮协作与链式回放验收

2026 年 11 月 17 日，使用 DSH 0.2.2-rc.1 和 `deepseek-v4.1-flash`，在可见 Linux 桌面测试 Bootstrap 5.3 Accordion。每轮先用无参数的 `/autoskill-use` 加载技能，再发送一条自然语言需求。父会话使用 DSH 原生子智能体执行，验收从宿主事件、运行记录、桌面窗口和实际交付的文件取证。[Bootstrap Accordion](https://getbootstrap.com/docs/5.3/components/accordion/)

## 从现有用例接续业务

| 操作 | 可核对的结果 |
| --- | --- |
| 第一轮复用 `TC-UI-003` v1 展开 Item #2，再点击 Item #1 | 子智能体先生成 14 列初始设计，再在可见窗口续录。运行 `run-4824da503a42` 验证 #1 正文展开、#2 正文折叠，发布 `TC-UI-004` |
| 第二轮复用刚保存的 `TC-UI-004` 继续测试 Item #3 | 新用例依次执行固定的 `TC-UI-003` v1、`TC-UI-004` v1。点击前验证 #2 的按钮属性为 false，随后只新增一次点击 #3。点击后验证 #3 正文展开、#1 正文折叠，两个按钮属性分别为 true 和 false。五项检查通过，`run-805c640f4e6b` 发布 `TC-UI-005` |
| 从 DSH「可复用用例」手动回放 `TC-UI-005` | 在 `Bootstrap / 组件 / Accordion / 展开互斥` 点击一次启动。运行 `run-79fce589b35d` 按两个原版本与内容哈希回放，五项检查通过。手动操作期间，DSH 全部会话的模型请求及用量记录增量均为 0 |
| 第三轮在精简版技能里要求多智能体按原预期回归 `TC-UI-005` | 子会话复用已发布资产，入队和回放各一次，`run-71e3cd94f81f` 两个前置和五项检查均通过。录制数为 0，三个用例文件的内容哈希与输入一致 |

第一轮设计额外写了 #2 按钮的属性值，点击后的回放仅检查了用户要求的两项正文状态与 #1 属性。原始回执保留这一缺口。第二轮在操作 #3 前独立执行了这条属性检查。现在技能要求按设计逐项核对目标元素、验证时点和实际 `check`，并将低频操作配方移到按需参考。

两次续测都在同一条业务请求内完成委派。第一轮父会话在委派前仅做探查。第二轮父会话先进行了 26 次只读工具调用，又用空设计试调一次 `plan write`。输入被拒绝，正式设计表由子智能体创建。第二轮还为前置单独启动了一次已有用例回归 `run-3accdb561a38`，随后才用 `--reuse` 接续。精简版入口增加了可直接使用的设计 JSON 示例，并明确同页前置本身就会执行和验证固定版本。父子分工由宿主模型选择，每次的工具顺序以实际事件为准。

第三轮也仅发送一条业务需求。父会话在委派前做了八次只读调用。执行方完成设计和已有用例回归，直接读取确切 run ID。父会话按确切 report ID 复核了关联该运行的整表与通过数量，独立查询运行明细的次数为 0。这轮没有提前写表或重复录制。

## 可见窗口与斜杠

第二轮的单独前置、录制与新用例回放分别观察到三个独立 Chromium 进程。三次目标窗口均为 X11 `IsViewable`，启动参数里没有 `--headless`。同一窗口编号曾被不同进程复用，按窗口编号和进程编号同时核验。手动回放也观察到了独立的可见 Chromium 窗口。

在另一个隔离 DSH 实例的空会话执行斜杠，原生界面显示一次「已加载 autoSkill 技能。请直接描述要完成的任务」。刷新、重开同一会话后仍只显示一次，切换到另一空会话时该提示消失。320 至 1420 px 五种视口均可读。该次激活的模型轮次、请求及 ToDo 写入都是 0。三轮业务父子会话同样没有写入 DSH 原生 ToDo。

在实际 DSH 744 px 宽的嵌入面板切换三个页面，六次测量的导航高度均为 49 px，展开菜单均为 464 px，横向溢出为 0。

旧资产允许单独的子项目字段为空或显示「未分组」，实际文件夹由项目目录树记录。在「全部用例」搜索「组件」和 `Bootstrap/组件/Accordion/展开互斥` 都能找到 `TC-UI-005`，详情显示相同的完整目录。输入无匹配词会移除该行。搜索和查看详情期间新增运行数为 0。

## 模型输入开销

按同一运行绑定，调整前实际注入的完整技能为 59,655 字节，精简后为 37,180 字节，减少 37.67%。长命令前缀从 71 处减为 31 处。浏览器细节、冷 API 验证与导出操作可按需读取。该对比按 UTF-8 字节计量。整个模型任务还包含系统上下文、工具结果和各轮输出，尚无相同任务的总 Token 对照。
