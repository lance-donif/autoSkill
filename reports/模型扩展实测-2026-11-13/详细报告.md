# autoSkill 五款候选模型 CPU 实测报告

本批拆步模式中，Kev 0.8B 的结果为 14/16，正向任务 12/14。 五款均使用真实本地权重运行；结果只代表这批固定任务。主模型仍为 `deepseek-v4.1-flash`。

本轮共同拆步协议的最高结果比上轮 OpenDecider Nano 的 13/16 多 1 轮；这是同一固定任务集的跨批观察，仍需重复验证。

本轮主模型回执实际标识：`deepseek/deepseek-v4.1-flash-1017`；无静默重试或小模型失败后兜底。每个计分工作进程仅加载一次，先做两次不计分预热；加载时间单列，任务耗时不含模型加载和最终截图保存。

## 耗时与资源

所有小模型为 CPU。实际配额 2 核、内存限制 8 GiB，浏览器 Chromium、Playwright，单模型顺序运行。Laya 两款和 Kev 为 FP32；Verdict 为 ONNX INT8；Qwen 为 GGUF Q4_0。混合精度适合评估部署成本，但不能据此声称等精度架构速度排名。

小模型计分进程启用 HF/Transformers 离线模式，本地权重与页面快照不依赖联网。主模型逐步决策以及上轮计划生成使用远程 API，因此这不构成整套系统完全离线运行的证明。

## 各模型实际接法

- Laya Browser：共同整任务/局部选择协议共 32 轮；作者 `laya_browser.py` 格式接宿主动作目录另 16 轮。后者把动作描述作为控件名称，与训练格式存在差异，故保留全部初测数据，再另加控件名称/实际可用元素 16 轮修正补测。补测还把历史 kind 改为 fill/click/select，并填入已执行动作绑定值；按真实观察排除不存在的主框架字段、customer-id 和尚未可见的动态输入框。没有按最终判据或主模型答案过滤候选。补测是看到初测结果后发现适配差异而追加的探索，不能作为事前冻结的纯格式因果实验；改动同时包含名称和候选可用性。iframe/弹窗仍是宿主宏，没有宣称跑了完整 Jev Browse 产品。
- Laya Multilingual：`laya` 官方加载，CPU eager，固定权重、2 线程，沿用共同问题协议。SDK 0.4.31 自动将 tokenizer_config 的 extra_special_tokens 列表改成 extra_N 映射以兼容 Transformers 5；已核对完整 JSON 恰好只发生这一表示转换。原始文件、运行时文件、前后 SHA 和 token ID（106、107）分别保存；tokenizer.json 和权重未变。未把这项已确认的 SDK 规范化错误描述为权重变化或模型测试失败。
- Verdict Small：官方 INT8 ONNX，E5 `query:` / `passage:` 前缀，attention-mask 均值池化与 L2 归一化，cosine×20；512 token 截断，缓存选项嵌入，未缓存答案。它测的是候选语义匹配，不能当完整推理代理。
- Qwen3.5 0.8B：官方 GGUF Q4_0，llama.cpp b12360 CPU，4096 上下文，关闭 thinking，JSON schema 约束选择一个候选；每步真实生成并解析 JSON，未使用主模型答案或规则替代生成。
- Kev 0.8B：作者固定 GitHub 源码，原版 LoRA adapter＋`head.pt` 指针头＋固定 Qwen3.5 0.8B Base，CPU FP32。没有把普通 Qwen 生成当作 Kev。

## 解释边界与建议

Kev 拆步失败记录：03_checkbox_radio/en：uncheck_checked → radio_default；03_checkbox_radio/zh：uncheck_checked → radio_default。这些错误仍计为失败；主模型给定了操作类型，也不能保证小模型选对控件。

测试通过 autoSkill 原有 `ui.perform`、PlaywrightDriver 和 `ui.check` 路径执行，未给生产内核增加模型 SDK。iframe、弹窗和缺失元素使用上一轮相同宿主适配器。候选动作、选择器、填写值由宿主提供；这里不验证任意网站导航、截图识别、自动发现 DOM、验证码或在线实时 Selenium 网站。

小模型不接收评分 oracle，也不接收计划的 action_id；后者仅用于直接执行对照和事后诊断。计划按命令实际分派是否成功推进，不按小模型是否选对推进；同样的步数上限与连续两次无进展停止规则沿用上轮。失败早停不会改为成功，正确报告缺失也单列。

对于本批边界明确的任务，使用一次规划加确定性执行作为当前优先方案；需要每步观察和恢复时再用主模型做条件重规划。本批模型结果可筛选候选，但尚不足以直接替换主模型：每种语言仅 8 轮，未做多轮重复和真实业务页面验证。浏览器格式接法与共同单题接法的差值只说明这个模型与该适配器组合，不能推成所有小模型采用 Jev 格式都会提升。
