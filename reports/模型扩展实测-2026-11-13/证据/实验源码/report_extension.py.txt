def read(name):
    return [json.loads(x) for x in (RESULTS/(name+'-episodes.jsonl')).read_text().splitlines()]


def formatted(value, places=2):
    return '—' if value is None else f'{value:.{places}f}'

## 各模型实际接法

- Laya Browser：共同整任务/局部选择协议共 32 轮；作者 `laya_browser.py` 格式接宿主动作目录另 16 轮。后者把动作描述作为控件名称，与训练格式存在差异，故保留全部初测数据，再另加控件名称/实际可用元素 16 轮修正补测。补测还把历史 kind 改为 fill/click/select，并填入已执行动作绑定值；按真实观察排除不存在的主框架字段、customer-id 和尚未可见的动态输入框。没有按最终判据或主模型答案过滤候选。补测是看到初测结果后发现适配差异而追加的探索，不能作为事前冻结的纯格式因果实验；改动同时包含名称和候选可用性。iframe/弹窗仍是宿主宏，没有宣称跑了完整 Jev Browse 产品。
- Laya Multilingual：`laya` 官方加载，CPU eager，固定权重、2 线程，沿用共同问题协议。SDK 0.4.31 自动将 tokenizer_config 的 extra_special_tokens 列表改成 extra_N 映射以兼容 Transformers 5；已核对完整 JSON 恰好只发生这一表示转换。原始文件、运行时文件、前后 SHA 和 token ID（106、107）分别保存；tokenizer.json 和权重未变。未把这项已确认的 SDK 规范化错误描述为权重变化或模型测试失败。
- Verdict Small：官方 INT8 ONNX，E5 `query:` / `passage:` 前缀，attention-mask 均值池化与 L2 归一化，cosine×20；512 token 截断，缓存选项嵌入，未缓存答案。它测的是候选语义匹配，不能当完整推理代理。
