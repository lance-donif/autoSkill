# DSH 用例编辑与复杂定位验收

这是 v2.3.0 发布后 main 新增功能的真实 DSH 界面验收，最终源码 b566f4e。通过真实浏览器操作官方 DSH 内的 autoSkill 仪表盘，保存表单并手动启动实际回放。本轮不使用新的模型任务，不将预置合成用例称为模型自行设计或录制。

- UI/API 表单保存、完整定义重读、保存不自动执行、旧 Pass 失效及手动回放通过。
- 多层 iframe/open Shadow DOM 的实际回放通过，末位 XPath 候选实际兜底 3 次；独立服务端命中仅在目标叶层。
- 两个真实表单产生的 409 保留本地草稿；Escape、路由和真实宿主刷新保护已验。首轮路由背景错误已修复并定向复验，原失败记录保留。
- closed Shadow DOM 明确失败；手工业务预期变化后的旧技术检查即使通过，界面仍显示业务未验证。
- 实际 Excel 下载保留手工业务正文，步骤/预期按 Skill 编号。合成项目复用前缀导致导出待确认编号，该输入缺口不称为来源完整。
- 实际 712/656 像素 iframe 无横向溢出、保存/取消可见；无页面脚本异常。保存的隐藏浏览器偏好对应真实 runner-owned Chrome 的 headless 参数。
